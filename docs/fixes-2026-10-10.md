# WhatsLearn v19 fixes (10 October 2026)

Made on a copy of `WhatsLearn-project-v19-2026-10-10.zip`. The live site and GitHub were not touched.
No original file was deleted and no existing wording was removed or reworded. Changes are additions, plus small code edits in `app/learn/page.tsx` and `components/whatslearn/language-picker.tsx` needed for the fixes.

## Fixed

| Issue | Fix | Files |
|---|---|---|
| Hero starter not carried into the full mission or My Creations; marketing and development switch scenario | The first mission in each programme now shows a "Continuing your agency story" card with the learner's starter piece, a line that ties the agency client to the mission scenario (home-meal service for marketing, tutor booking build for development, and so on) and a "Start from my starter piece" button that puts it into the editor. My Creations has a new "Starter pieces" section, and Export includes them. | `lib/starter-bridge.ts` (new), `app/learn/page.tsx`, `app/globals.css` |
| Opening a mission from another programme doesn't switch programme; "Next challenge" returns to the old one | Opening any mission now selects its programme, so the journey, path and next challenge follow it. | `app/learn/page.tsx` |
| Unsaved editor writing lost on close/reopen or refresh | Writing is saved on the device as you type and restored when the mission reopens. The open mission is kept in the address bar, so a refresh reopens it. The draft is cleared once the creation saves. | `lib/mission-drafts.ts` (new), `app/learn/page.tsx` |
| `/privacy` and `/terms` return 404 | New Privacy and Terms pages in the existing account-page style, marked "Draft for legal review", linked from the home, journey, path-finder and account footers. | `app/privacy/page.tsx`, `app/terms/page.tsx`, `components/whatslearn/legal-page.tsx` (new), `app/page.tsx`, `app/find-my-path/page.tsx`, `components/whatslearn/account-shell.tsx`, `app/globals.css` |
| ChatGPT companion has no direct install path | The "How to add it" box shows an "Add WhatsLearn to ChatGPT" button once you paste the public install link into `lib/companion.ts`. Until then it says plainly that no public link exists yet and offers "Request the installation card" (WhatsApp) or email. The original sentence stays; the box is added below it. | `lib/companion.ts` (new), `app/companion/page.tsx` |
| Language coverage unclear | All 23 options stay. Languages without full lessons are labelled "English guidance for now" in Find my path and Settings; in the hero story picker, languages without a story translation are labelled "story in English for now". | `lib/languages.ts`, `components/whatslearn/language-picker.tsx`, `components/whatslearn/visual-start.tsx`, `app/settings/page.tsx` |

## How to run

```
cd WhatsLearn
pnpm install        # or: npm run install:ci
npm run dev         # http://localhost:5173
npm run build       # production build
```
Node 22.13 or newer.
