# WhatsLearn v38 (12 October 2026), built on v37

Not deployed or published. The original ZIP, source project, live Site and live database are untouched; v37 and earlier ZIPs are unchanged. No database change (no new migration), no UI redesign (text in the existing rewards panel only).

## Decisions applied (from Shreedhar)
- **Starting balance stays at 50** (`STARTING_POINTS` default, unchanged).
- **Two separate rules, now stated separately in the rewards explanation:**
  1. **Daily streak:** one new scored mission, in any course, on each consecutive India-time (Asia/Kolkata) day. Repeating a finished mission (practice) does not count, and clue use neither counts for nor against it. A missed day resets only the current streak; points, work and titles stay.
  2. **10-day no-clue title** (Campaign Director, Full-Stack Lead, Film Director, Creative Director): all 10 missions of **one** course, **no clue anywhere in that course**, and one new mission per day on 10 consecutive India-time days, **all in that course**. A day spent on another course, or a missed day, breaks that course's run and it must be restarted. Any clue in the course rules the title out for that course (the learner still earns the practitioner title on finishing). A title once earned is never removed.
  The v37 wording ("10-day run may include other courses") is replaced.
- The rewards panel's streak figure is now this mission streak (before: practice days). The separate "practice days" figure is unchanged.

## Tests added or changed (`tests/points-balance.cjs`, now 16 tests)
- Daily streak: consecutive days, yesterday still counts, missed day resets only current, best kept, same day counted once.
- India midnight: 23:59 IST vs 00:00 IST, run under five device time zones (India, Los Angeles, Auckland, London, UTC) so a learner anywhere gets the India day.
- Server: practice repeat does not extend the streak; a clue neither adds nor removes a day; the 18:29/18:31 UTC boundary.
- Title: earned in a clean run (also across a month end); denied for a clue on any mission, a gap, a mixed-course day, spreading over more than 10 days, ten missions on one day, and fewer than 10 missions; the same checks through real saved missions on the server.
- `tests/mission-points.cjs` and `tests/progression.cjs`: two assertions updated to the new wording and streak line.
