# Changes in v50 (2026-10-13), on top of v49

WhatsApp learning workflow with n8n. UI layout, scoring, clue costs, streaks, daily limit and entitlements are unchanged.

## New files
- `drizzle/0011_whatsapp_bridge.sql`: adds verified/reminder columns to `whatsapp_contacts`; tables `whatsapp_link_codes`, `bridge_nonces`, `whatsapp_tutor_usage`, `whatsapp_drafts`, `whatsapp_outbox`, `whatsapp_reminder_log`. Not applied anywhere.
- `lib/bridge/auth.ts`: signed-request check (HMAC, 5 minute window, one-time nonce, safe retry).
- `lib/bridge/whatsapp-chat.ts`: linking, commands, guided mission draft, tutor material, reminder settings.
- `lib/bridge/whatsapp-jobs.ts`: reminder and notice claim/report.
- `lib/bridge/notify.ts`: website-to-WhatsApp notices.
- `app/api/bridge/whatsapp/message/route.ts`, `.../outbox/route.ts`, `.../reminders/route.ts`.
- `n8n/workflows/whatslearn-1-incoming-chat.json`, `whatslearn-2-website-sync.json`, `whatslearn-3-reminders.json`.
- `n8n/code/*.js` (Code node bodies), `n8n/gen_sdk.py`, `n8n/build_json.cjs` (rebuilds the JSON).
- `tests/whatsapp-bridge.cjs` (22 tests).
- `docs/whatsapp-n8n-setup-v54.md`, this file, `docs/handoff-v50-2026-10-13.md`.

## Changed files
- `drizzle/meta/_journal.json`: entry 0011.
- `lib/whatsapp.ts`: legacy matching needs a verified link; reminders use the new claim/report.
- `app/api/whatsapp/route.ts`: opt-in starts linking and returns a one-time code; opt-out unlinks.
- `components/whatslearn/whatsapp-optin.tsx`: shows the code and a "send LINK" step; consent text says reminders are set in WhatsApp.
- `app/api/work/route.ts`: queues a WhatsApp notice after a saved mission.
- `app/api/checkpoint/route.ts`: queues a notice on a newly earned badge.
- `.env.example`: `N8N_BRIDGE_SECRET=` (placeholder).
- `docs/deployment-guide.md`: migrations now 0000 to 0011.
- `tests/migrations.cjs`, `tests/whatsapp-ai.cjs`: updated for 0011 and verified linking.

## Behaviour notes
- Unverified numbers from earlier versions are ignored until re-linked.
- Existing "opted in" users get no reminders until they set a time with REMIND in WhatsApp.
