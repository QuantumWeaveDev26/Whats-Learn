# WhatsLearn v39 (12 October 2026), built on v38

Not deployed or published. The original ZIP, source project, live Site and live database are untouched; v38 and earlier ZIPs are unchanged. No database change, and no change to UI, layout, styling, navigation, scoring or mission progression: only the text inside the existing feedback areas.

## What was wrong
Four kinds of multiple-choice question judged a wrong answer in vague words:
- **Home starter challenge (4 questions):** "A useful instinct. Here's another angle." and "You're thinking like a maker."
- **Visual/agency starter (14 languages):** "Try the other angle." (and the equivalent "see the other option" in each language) and "A useful first move."
- **Side quests (every mission, 23 languages):** a bare "Try again. Use the clue below." with the explanation.
- **Side-quest server message:** "Try the other choice using the hint."
(The 40 mission questions were already direct since v37.)

## What every one of them says now
- Wrong: **"That answer is not correct."**, the reason, and "Choose another answer. A wrong answer costs no points and does not lock anything." (mission questions also name the concept to reconsider).
- Right: **"Correct."** and why it works.
- The wording lives in one place, `lib/quiz-feedback.ts`, in all 23 interface languages. English, Hindi and Kannada are direct; 15 more are machine drafts waiting for native review; Bodo, Manipuri, Kashmiri and Santali show English until reviewed (unchanged from v37).

## Unchanged and re-tested
A wrong attempt is never saved, never locks, never unlocks the next mission and never changes points, work or clues. Clues cost points only when revealed, with the cost printed on the button first, once per clue.

## Tests (`tests/answer-feedback.cjs`, new, 8 tests)
Source scan for vague wording; home starter (all 4) right/wrong text and retry; agency starter in all 14 languages; every side quest in six languages; all 40 missions, every option, all 23 languages; wrong answers repeated three times on one mission of each of the four courses change nothing (ledger, scores, work, clues) and leave the next mission locked, then the right answer scores once; clue cost shown first and charged once; side-quest API refuses a wrong choice with the plain message and records nothing, then accepts the right one.
