# v40 (2026-10-12): ready to deploy as a regular website with email accounts

Base: v39. Nothing was deployed, published, migrated on a live database, or paid for. Originals untouched.

## Hosting finding
OpenAI Sites supports only ChatGPT sign-in and owns the sign-in paths and headers, so email/password cannot exist there. Chosen host: **Cloudflare Workers + D1 (+ R2)** with **Supabase Auth**. Reasons and alternatives: `docs/deployment-guide.md`. Without the `SUPABASE_*` settings the app behaves exactly as v39 (host mode).

## Added
- **Accounts** (`lib/auth/*`, `app/api/auth/*`, pages `/signup /signin /signout /verify-email /auth/confirm /forgot-password /reset-password`): sign-up with name, email, password (no phone), confirmation by emailed link, sign-in, sign-out, forgot and reset, resend, account deletion. Clear messages for invalid credentials, unconfirmed email, expired or used links, network failure and rate limits. Safe return to the origin page. Forged ChatGPT headers ignored in email mode. Per-address and per-email attempt limits (`auth_attempts`, hashed), Origin (CSRF) check, strict validation, `__Host-` HttpOnly cookies, no password or token ever logged or sent to page JavaScript.
- **Points**: unchanged v37 ledger; welcome balance once per account (also after deletion and re-signup via an empty marker row).
- **Reward** (`lib/reward-config.ts`, `lib/rewards.ts`, `/api/rewards`, `/api/admin/rewards`): off until `REWARD_PLAN` and `REWARD_DAYS` are set; earned only by the real server-computed rule; one request per account; owner approve/decline/revoke; account-bound entitlement (mode `reward`), not a payment; progress toward every title shown in the rewards help.
- **Uploads** (`lib/uploads.ts`, `/api/uploads`, `/api/uploads/[id]`, `upload-control.tsx`): off until `UPLOADS_ENABLED=true` and an R2 bucket named `BUCKET`; type from file bytes; size/count limits; private, owner-only attachment downloads; deletion; never claimed as AI-reviewed.
- **Settings**: "Delete my account" card (email accounts only). **Privacy page**: new section 8A.
- **Build**: `CF_D1_DATABASE_ID`, `CF_D1_DATABASE_NAME`, `CF_R2_BUCKET_NAME` build-time names; `wrangler deploy --dry-run` succeeds.
- **Docs**: `docs/deployment-guide.md`, `docs/sign-in-hosting.md` (rewritten), `docs/handoff-v40-2026-10-12.md`, this note; `.env.example` placeholders.
- **Migration** `drizzle/0009_accounts_rewards_uploads.sql`: three new tables only.

## Changed behaviour
- Sign-in aliases `/forgot-password`, `/reset-password`, `/verify-email` are real pages now (they no longer redirect to `/signin`).
- Account deletion stops if a stored file cannot be removed.
- Existing visible interface: only the additions above; the interface-fingerprint test records them.

## Test doubles
`scripts/fake-auth-core.cjs` and `scripts/fake-auth-provider.mjs` model the provider's documented API for tests and local journeys only. They are not a login system and are never used when real settings are present.
