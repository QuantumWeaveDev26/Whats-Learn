# WhatsLearn v21 changes (10 October 2026)

Built from the v20 ZIP. Adds OpenAI as an optional AI provider for live writing feedback and Ask WhatsLearn; Claude support is unchanged.

- `lib/ai-feedback.ts`: one shared prompt and feedback format, sent to OpenAI (Chat Completions) or Claude (Messages API). Provider choice: `AI_PROVIDER` (`openai` or `anthropic`) when its key exists; otherwise whichever key is set; Claude when both are set and no choice is made. `OPENAI_MODEL` is optional (default `gpt-4o-mini`).
- Daily limits, sign-in, the no-key fallback and the WhatsApp answer review work the same with either provider.
- `tests/ai-provider.cjs`: provider selection, OpenAI and Claude paths, custom model, error and allowance checks, with both APIs faked.
- README, `.env.example`, `docs/go-live-setup.md`: new settings and local setup with `.env.local` (git-ignored) using placeholders only. Privacy policy names OpenAI or Anthropic as the AI provider.
