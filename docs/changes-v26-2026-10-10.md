# v26 changes (10 October 2026)

Built from v25 (the uploaded WhatsLearn.zip was identical to v25). v20 to v25 are unchanged.

- **Local test sign-in for the built preview.** `pnpm start` now runs `scripts/local-preview.mjs`: Wrangler serves the built site on an internal loopback port and a small proxy on `http://127.0.0.1:8787` adds the same test sign-in as `pnpm dev` (`seedy@sites.test`). Loopback hosts and callers only; sign-in headers sent by a browser are always removed; not part of the published build. `pnpm start:no-signin` turns it off.
- **Settings for `pnpm start`.** `.env` and `.env.local` are now read from the project folder (Wrangler looked next to the build, so keys in `.env.local` were ignored).
- **`pnpm db:local`** applies every migration in `drizzle/` to the local database once, in order (`scripts/local-db.mjs`). `pnpm start` warns when migrations are missing.
- **Updates feed.** Its 503 came from missing local database tables. On localhost the home page now says updates are not available in this local preview.
- **Razorpay test checkout.** `lib/billing/setup.ts` builds a checklist (sign-in, `RAZORPAY_KEY_ID` test key, `RAZORPAY_KEY_SECRET`, `RAZORPAY_WEBHOOK_SECRET`, `BILLING_ADMIN_EMAIL`, database tables, test plans), names only. The membership dialog and `/billing/setup` show what is missing. Live payments still need an `rzp_live_` key and `BILLING_LIVE_ENABLED=true`; neither is set anywhere.
- **Answer relevance.** The home starter piece (`components/whatslearn/visual-start.tsx`) saved any text of 10+ characters. It now runs `lib/starter-check.ts`: rejects pasted logs, code or terminal output, random letters, and text unrelated to the task, with a helpful message; short answers in supported languages pass. `lib/text-signals.ts` also feeds the mission writing check. Save messages say it was a check on the device, not an AI review.
- **Guest vs signed in.** The Learn page explains guest mode (saved in this browser only) and what needs sign-in.
- **README:** Windows (PowerShell) steps for build, local database, test sign-in and Razorpay test checkout.
- **Tests:** `tests/local-signin.test.mjs`, `tests/answer-relevance.cjs` (with `tests/fixtures/wrangler-log.txt`), `tests/billing-setup.cjs`.
