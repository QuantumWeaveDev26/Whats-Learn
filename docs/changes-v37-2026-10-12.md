# WhatsLearn v37 (12 October 2026), built on v36

Not deployed or published. The original ZIP, source project, live Site and live database are untouched. No GitHub, no real payments or messages, no secrets.

## 1. Sign-in and sign-out
- **Finding:** name/email/password accounts cannot be provided on the intended host. OpenAI Sites hosting offers ChatGPT sign-in only and owns the sign-in paths, so there is no place to add custom credentials. Nothing was faked and no password code was written. Full table of methods per host, and what a real email/password login needs, is in `docs/sign-in-hosting.md`.
- Every sign-in/sign-out link now goes to WhatsLearn's own `/signin` and `/signout` pages with `?return_to=<current page>`. They check whether you are already signed in, check that the host's ChatGPT sign-in exists, and hand over. If it does not (any host other than Sites), a plain explanation replaces the 404, with a guest option.
- `return_to` only accepts paths inside this site.
- Typed-by-hand addresses redirect instead of 404: `/login`, `/log-in`, `/sign-in`, `/signin-with-email`, `/register`, `/sign-up`, `/forgot-password`, `/reset-password`, `/verify-email`, `/logout`, `/log-out`, `/sign-out`, `/account`.
- New 404 page with working links (My Journey, Home, Sign in).
- Email verification and password reset do not exist in the app because there are no app passwords. They are part of the provider setup in the doc.

## 2. Answer feedback
Wrong understanding answer: "That answer is not correct.", then "Concept to reconsider: <skill>", the reason, and "Choose another answer. A wrong answer costs no points and does not lock anything." Right answer: "Correct." and the reason. A wrong answer is never saved, never locks, never unlocks the next mission and never changes points. Lines are in `lib/quiz-feedback.ts` for all interface languages: English, Hindi and Kannada, plus machine drafts for 15 more (waiting for native review). Bodo, Manipuri, Kashmiri and Santali show the English line for now rather than a guess.

## 3. Points balance
- New table `point_ledger` (migration `drizzle/0008_points_ledger.sql`). Balance = sum of the learner's rows. One row per grant or charge; a unique index (user, kind, ref) makes repeats, refreshes, retries and second tabs harmless.
- **Starting points:** setting `STARTING_POINTS` (whole number 0 to 10000). **No amount was configured anywhere in the project, so the proposed default is 50**, used when the setting is empty or invalid. Granted exactly once per account the first time it loads, saves or reveals a clue (existing accounts get it once on their next visit). Changing the setting later never tops up an existing account.
- **Missions:** points are added once when a mission is first scored, as before (25 + 75, minus clue costs).
- **Clues:** the cost (5 points per clue, at most 10 per mission, existing rule) is shown on the button before the click and taken from the real balance in the same step the clue is revealed. The same clue never costs twice. If the balance cannot cover it, the clue stays hidden and the learner is told. The balance cannot go below zero. A completed mission's clues cost nothing. Mission points add back the clue costs already charged, so each clue is paid exactly once in total.
- Earlier mission scores are carried into the ledger by the migration.
- The balance appears in the existing practice line of the rewards panel. Guests get no starting balance; their points stay on the device and are labelled as not saved to an account and not synced.

## 4. Mission order and daily limit
Unchanged from v36 and re-tested: server-enforced locks, explanation of what to finish next, no duplicate completion points, one new scored mission per India-time day across all four courses, next mission waits for a later day. New check at the 18:30 UTC boundary.

## 5. Titles and streak
Three tiers per course, highest first: **Campaign Director / Full-Stack Lead / Film Director / Creative Director** (all 10 missions, no clue used, and 10 consecutive India-time days each with a new scored mission), then the existing top titles (all 10, no clues), then the practitioner titles (all 10, clues used). The 10-day run may include missions of other courses and is the best run ever, so a missed day resets only the current streak and never removes points, work or a title. Computed on the server from `mission_scores`; `/api/work` also returns the current and best streak. No leaderboard exists. Any future one must be opt-in and must not show names, emails, work or scores.

## 6. Course content
No change this version. Course-specific questions and practical tasks from v36 stay. **Uploads are not built:** they need file storage (for example R2) and server-side validation that is not set up on this host, so v36's link field stays the way to share images and video.
