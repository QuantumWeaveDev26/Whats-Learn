# Changes in v51 (2026-10-13), on top of v50

Only the n8n packaging changed. The WhatsLearn backend, migrations and UI are identical to v50.

## Changed
- The three workflows (chat, website sync, reminders) are merged into ONE workflow: `n8n/workflows/whatslearn-all-in-one.json` (42 nodes incl. 3 section notes, 3 entry points: Meta webhook, every 2 minutes, hourly at :07). Same logic, same Code nodes, same signed calls.
- Removed from `n8n/workflows/`: `whatslearn-1-incoming-chat.json`, `whatslearn-2-website-sync.json`, `whatslearn-3-reminders.json` (still in the v50 folder).
- Node names that existed in both sync and reminders got a prefix: `Notices: Sign Claim Request`, `Notices: Sign Report Request`, `Notices: Tell WhatsLearn It Was Sent`, and the same three with `Reminders:`.
- New: `n8n/gen_merged.py`. Changed: `n8n/build_json.cjs` (now writes the single merged file; run `node n8n/build_json.cjs`).
- Docs: `docs/whatsapp-n8n-setup-v54.md` (replaces the v50 guide name), this file, `docs/handoff-v51-2026-10-13.md`; v50 changes and handoff files keep their text with the guide link updated.
- `tests/whatsapp-bridge.cjs`: unchanged.
