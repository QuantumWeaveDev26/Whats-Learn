# WhatsLearn v40 handoff (2026-10-12)

ZIP: `WhatsLearn-project-v40-2026-10-12.zip`. Base v39. Nothing was deployed, published, pointed at a DNS name, migrated on a live database, or paid for. No real key or secret was used or asked for. Original ZIP, older versions, source project and live Site untouched.

## 1. What this version does
- **Hosting decision.** OpenAI Sites supports only ChatGPT sign-in, so email/password is not possible there. Recommended: Cloudflare Workers + D1 (+ R2) + Supabase Auth. The app picks the mode from its settings and never shows an email form that cannot work. Table of which sign-in works where: `docs/sign-in-hosting.md`.
- **A. Accounts.** Name, email, password (no phone); confirmation email; sign-in/out; forgot/reset; resend; account deletion; clear errors; safe return to origin; server-verified sessions on every account API; no custom password storage; rate limits, CSRF check, secure cookies.
- **B. Points.** Server ledger; 50 once per account (`STARTING_POINTS`); clue cost shown before reveal; charged once per clue; wrong answers cost nothing; never negative; guest points labelled this-device-only.
- **C. Courses.** 4 courses x 10 missions unchanged; server locks; "That answer is not correct." / "Correct."; one new scored mission per India day.
- **D. Practical work.** Existing structured tasks per course. Optional private uploads (images, PDF, short video) built but **off** until storage is set up. Code is never run; GitHub or demo links are text.
- **E. Streaks, titles, reward.** Daily streak and the 10-day no-clue title exactly as in v38; the separate completion titles for clue users; progress toward each is shown in the rewards help. Free-membership reward built as an owner-approved, one-per-account, account-bound entitlement; **off** until `REWARD_PLAN` and `REWARD_DAYS` are set. No leaderboard.
- **F. Services and deployment.** `docs/deployment-guide.md` (host, accounts, env names, DB/migrations/backup, email, DNS, Razorpay test and live, checklist, rollback, services inventory). `.env.example` has placeholders only.
- **H. Companion.** The button opens `https://chatgpt.com/g/g-683b056072048191a84d71e799ecbc26-whatslearn-from-chat-to-change` in a new tab (checked in a browser).
