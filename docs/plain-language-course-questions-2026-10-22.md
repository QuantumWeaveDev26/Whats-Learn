# Clear questions and everyday practice — 22 October 2026

## Scope

- Rewrote all 40 main questions across marketing, development, filmmaking and visual storytelling.
- Rewrote the 80 guided/stretch question variants using familiar situations and shorter choices. Each main/level question has one question mark and at most 40 words; all current choices are at most 24 words.
- Added a plain question for each of the 169 practical fields. Examples: “Which details must the parent enter?” and “What should people notice first on the poster?”
- Replaced dense task introductions with three actions: make something, try it, share the result and improvement. Level-specific extra practice remains separate.
- Simplified specialist phrases in style questions and follow-up practice cards. Styles still have distinct interactions and preserve the decision being assessed.

## Everyday situations

Marketing uses lunch offers, customer replies, local shops, small budgets and realistic posting time. Development uses class bookings, duplicate seats, failed saves, stock checks and private family records. Filmmaking uses phone shoots, lost items, light changes, sound jumps and limited shooting time. Visual storytelling uses library pictures, club posters, unreadable flyers, misleading charts and short slide sequences.

These are practice scenarios based on everyday problems. They are not live client requests, current news, verified campaign results or claims that a real organisation commissioned the work. No paid tools, real customer outreach or production deployment are required by these exercises.

## Website and WhatsApp

The website displays each field's new `prompt`; the original `label` remains the stored answer heading. WhatsApp shows that same question with the essential hint, including limits and examples. The two channels use the same course and level question banks. No separate n8n question copy needs updating for this change.

## Assessment and saved-work compatibility

The answer indices, field IDs, stored labels, field types, choice values, starter code and required code terms are unchanged. A regression test verifies a structural hash across all 40 missions and round-trips all 40 saved-answer fixtures.

Practical review still requires the learner's work, an actual trial, the observed result and an improvement. Shorter wording does not turn a plan or invented result into completed work. Reasoning checks for structured tasks no longer depend solely on whether a task paragraph happens to contain the word “why”.

Independent review found missing limits in the shortened instructions; these were restored. Regression coverage includes the 30-second/six-shot task, four-to-six dialogue lines, four sound timing rows, 30-second edit, film budgets, short chart caption, phone/quantity validation and five-part launch checklist. Complete essential hints remain visible in WhatsApp.

## Verification limits

Synthetic checks validate wording bounds, answer-key compatibility, task constraints, saved-answer parsing, web/WhatsApp prompt consistency, rejection of weak or off-topic work and the existing mentor flows. They do not establish that every learner will understand every question; a short usability review with first-time learners remains useful. Interactive browser access and actual WhatsApp delivery are still unverified in this task.
