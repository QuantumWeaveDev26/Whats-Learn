# WhatsLearn v23 changes (10 October 2026)

Built from the v22 ZIP.

**AI provider setting.** `AI_PROVIDER` accepts `openai` or `claude` (`anthropic` also works and means the same). The README, `.env.example` and setup guide now show `AI_PROVIDER=openai` or `AI_PROVIDER=claude`; the Claude key and model settings (`ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`) are unchanged. `tests/ai-provider.cjs` checks the `claude` value.
