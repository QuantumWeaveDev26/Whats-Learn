# WhatsLearn v20 changes (10 October 2026)

Built on the uploaded v19 project and the earlier fixes in `docs/fixes-2026-10-10.md`. No existing page was removed and existing wording was kept unless it would now be wrong. Setup: `docs/go-live-setup.md`. Install, keys and limitations: README.

## What was missing and is now built

| Area | Before | Now |
|---|---|---|
| Membership and checkout | Test-only Razorpay; no paid access | Verified payments grant paid access (sprint 7 days; subscriptions to period end). Cancel keeps access to period end. Full sprint refunds end access. Live charges need a live key **and** `BILLING_LIVE_ENABLED=true`; public checkout needs `BILLING_PUBLIC_CHECKOUT=true`. Optional ₹149 first-sprint credit offer. Test and live records kept apart. |
| Ask WhatsLearn and feedback | Prepared lesson text; feedback from the checklist only | With `ANTHROPIC_API_KEY`: "Get AI review of my writing" reviews the learner's text against each checklist item in their language, and "Ask your own question" answers about the mission. Sign-in, daily allowance (3 free, 10 paid). Without the key the old behaviour stays. |
| WhatsApp lessons and reminders | Switch stored a preference only | With Meta WhatsApp Cloud API keys: opt-in with number and consent in Settings; LESSON on WhatsApp sends the next challenge; answers get AI feedback; STOP/START; one daily reminder via a scheduled call; signed webhooks; duplicate deliveries ignored. |
| Languages | 20 languages fell back to English guidance | Draft lesson packs for all 20 (all 10 missions, side quests, prompts, labels), labelled "draft translation" with a feedback link. English, Kannada and Hindi unchanged. |
| ChatGPT companion | No install link | Unchanged switch in `lib/companion.ts` with a clear placeholder; request button stays. |
| Privacy, Terms, Refunds | Drafts; no refund policy | Privacy expanded for the DPDP Act 2023 (Data Fiduciary, children, retention, rights, Grievance Officer placeholder) and the new payment, AI and WhatsApp processing. Terms add renewals, cancellations, AI feedback and WhatsApp terms, IT Rules grievance route. New `/refunds` page in the same style, linked from every footer; uncertain points marked "Proposed". All still marked "Draft for legal review". |

## Engagement touches added (for review)

- AI review card: per-checklist ticks with one-line notes, one concrete "Next" step, and a "Review my latest version" loop after edits.
- Ask WhatsLearn: free-text question box (Enter to send), "Thinking…" state, remaining daily count.
- Membership: "Your plan: … active until …" banner; dialog switches to "pay securely with Razorpay"; after payment the banner refreshes and a "Go to my journey" button appears; clear success, closed and failed messages.
- Settings: WhatsApp opt-in with consent, instant "WhatsApp lessons are on" state, "Get today's lesson on WhatsApp" button and one-tap turn-off.
- My Journey: "Learn on WhatsApp" dialog points to the opt-in once WhatsApp is live.
- Draft-language notice with a WhatsApp feedback link and a route back to English.
- Gentle reveal animation on new feedback, plan and opt-in states, switched off for reduced-motion users; busy cursors on working buttons; all new controls are labelled for screen readers and keyboard reachable.
