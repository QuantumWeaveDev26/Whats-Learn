# v28 changes (10 October 2026)

Built from v27 (which holds the deployment sign-in review). v20 to v27 are unchanged.

- `/billing/setup` is owner-only: a server check (`lib/billing/owner-gate.ts`) shows the tool to `BILLING_ADMIN_EMAIL` and returns 404 to everyone else. Before an owner is configured, only 127.0.0.1/localhost shows a one-line "how to become the owner" note. The page is marked noindex. The client part moved to `components/whatslearn/billing-setup.tsx`.
- `/api/billing` GET: guests and customers receive only checkout state and their own plan; setup checklist, configuration flags and plans go to the owner only.
- Membership page: no setup steps, setting names or owner links; it says "Paid checkout is not open yet" until checkout is open.
- Test mode is always owner-only (`publicCheckoutOpen()` needs live mode + `BILLING_LIVE_ENABLED=true` + `BILLING_PUBLIC_CHECKOUT=true`), so test payments can never give customers paid access.
- Tests: `tests/billing-setup.cjs` rewritten for owner-only access and customer-safe responses; `tests/billing.cjs` and `tests/account-isolation.cjs` updated.
